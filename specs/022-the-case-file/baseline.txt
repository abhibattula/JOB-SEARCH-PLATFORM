T004a — FEED THROUGHPUT BASELINE (SC-012)          measured 2026-08-03
---------------------------------------------------------------------
Build: v2.1.0 (commit 03a5ff6), real Chromium, viewport 1366x768,
60 seeded jobs, network-isolated, sort=score, window=all.

  state                                fully visible   partly   row height
  -----------------------------------  -------------   ------   ----------
  first launch (What's New showing)          0            0        40.1 px
  new install (setup card showing)           0            0        40.1 px
  settled (both dismissed)                   6            7        40.1 px

  topbar height: 45.4 px

THE NUMBER TO BEAT FOR SC-012: **6 fully-visible job rows** at 1366x768.
Compact density must show at least 6. Anything less is a regression.

Findings this measurement produced, which no test would have caught:

  F-A  The feed shows SIX jobs per screen on a standard laptop. Roughly
       695 px of the 768 px viewport is consumed before the first job:
       topbar 45 + setup card ~240 + dashboard ~315 + toolbar ~95. The
       dashboard's three cards and the two-row filter toolbar are the
       bulk of it.

  F-B  On first launch of a new version the What's New panel fills the
       ENTIRE viewport — nine full-width bullets with no max-height —
       so a new install shows zero jobs until it is dismissed twice
       (What's New, then the setup card).

  F-C  `wait_until="networkidle"` never settles on the feed, because the
       5-second poll keeps the network permanently busy. This is FR-027
       observed from the outside: any tool that waits for a quiet network
       hangs on this page.

Both F-A and F-B are worth fixing in this feature and are not currently
in any FR. Raised for the applicant's decision rather than absorbed
silently — the scope was agreed as a redesign, not an IA change, and
collapsing the dashboard changes what the home screen IS.

halved what fits on screen. Compact now uses a 1.55 rem stamp and
tighter rows; comfortable keeps the roomy one.
